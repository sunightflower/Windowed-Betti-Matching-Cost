# Поля сохранённых данных

## `data/window_timings.csv`

| Поле | Содержимое |
|---|---|
| `z0,z1,y0,y1,x0,x1` | Полуоткрытые границы окна в массиве val; порядок осей z,y,x |
| `voxels` | Число вокселей окна |
| `t_median_s` | Медиана пяти значений фактического времени отдельного вызова, секунды |
| `t_cpu_median_s` | Медиана пяти значений процессорного времени, секунды |

## `data/observations.json`

| Объект | Содержимое |
|---|---|
| `shape`, `repetitions` | Форма входного массива и число технических повторов |
| `environment` | Характеристики исторического ПК и версии Python/NumPy |
| `implementation` | Исходный проект, версия, компилятор и факт применения патча |
| `calibration.full_wall_median_s` | Медиана времени полного вызова на val |
| `calibration.configurations` | Геометрия шести покрытий и суммы медиан времени их окон |
| `calibration.alpha_wall_saved` | Сохранённый показатель степенной подгонки по фактическому времени |
| `test.checkpoints` | Полные проходы и медианы для трёх контрольных точек test |
| `test_larger_windows` | Дополнительная геометрия с собственной частью 64 и полем 4 вокселя |
| `parallel` | Геометрия, размер порции и медианы пакетного режима |
| `all_window_discrepancy.L_ratio` | Значение оконной функции потерь, делённое на полное |
| `all_window_discrepancy.cos` | Косинус угла между оконным и полным градиентами |
| `all_window_discrepancy.rel_l2` | Норма разности градиентов, делённая на норму полного градиента |

## JSON второго ноутбука

При `SAVE_RESULTS=True` файл `measurement_*.json` записывается в каталог `new_measurements` последней ячейкой ноутбука.

| Поле | Содержимое |
|---|---|
| `mode`, `stage` | Быстрый или полный режим; выбранная стадия |
| `shape`, `repetitions` | Форма массива и число повторов |
| `input_sha256` | SHA-256 входного архива; `null` для синтетического входа |
| `created_utc` | Время создания записи в UTC |
| `parallel_chunk` | Заданный максимальный размер порции окон пакетного вызова |
| `environment.python`, `os`, `numpy` | Версии Python, ОС и NumPy |
| `environment.cpu` | Модель или доступный идентификатор CPU |
| `environment.cores_physical`, `cores_logical` | Физические ядра и логические процессоры по данным psutil |
| `environment.ram_gb` | Общий объём ОЗУ в ГиБ, вычисленный делением числа байт на 1024³ |
| `environment.bm_binary_sha256` | SHA-256 фактически загруженного модуля Betti matching |
| `calibration` | Координаты окон, отдельные времена и медианы калибровочного прогона |
| `test` | Времена прямых проходов и их медианы по вариантам |
| `parallel` | Времена пакетных проходов и их медианы |
| `discrepancy` | Контрольная точка, геометрия и `L_ratio`, `cos`, `rel_l2`; `null`, если контроль не выполнялся |

В режиме quick контроль функции и градиента выполняется автоматически. В полном режиме он включается параметром `RUN_DISCREPANCY`. Неопределённые отношения при нулевом знаменателе записываются как `null`.

## Таблицы и рисунки

`tables/table_1.csv` содержит шесть геометрий покрытия: ребро собственной части, поле, число окон, коэффициент повторной обработки, время и отношения времён. `tables/table_2.csv` содержит медианы последовательных полных проходов test для трёх контрольных точек. Первый ноутбук пересчитывает обе таблицы и строит рисунки `figure_1` и `figure_2`.
